🔍 TROUBLESHOOTING - IF LOGIN STILL FAILS
──────────────────────────────────────────

❌ Problem: "Invalid username or password"
→ Solution: 
  1. Make sure MySQL is running (XAMPP Control Panel)
  2. Run reset-admin.php again
  3. Check for typos (must be: admin / ncc123456)

❌ Problem: Page shows error
→ Solution:
  1. Press F12 in browser
  2. Look at Console tab
  3. Note any red error messages
  4. Run admin-debug.php

❌ Problem: Blank page
→ Solution:
  1. Check MySQL is running
  2. Check Apache is running
  3. Refresh page (F5)
