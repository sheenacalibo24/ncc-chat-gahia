## 🎓 HOW LOGIN WORKS

```
1. You enter username & password
2. Click "Login"
3. Browser sends to: controllers/AdminController.php
4. PHP checks database for user
5. PHP verifies password hash
6. If correct, creates session
7. Admin panel appears
```

If it fails at any step, the diagnostic file will tell you where!
